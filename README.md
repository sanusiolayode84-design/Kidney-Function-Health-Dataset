# 🩺 Kidney Disease Data Analysis

## 📌 Project Overview

This project focuses on analyzing kidney health data to explore patterns, identify potential risk factors, and understand indicators associated with Chronic Kidney Disease (CKD).

The dataset contains 5,000 records and 11 features, including creatinine, blood urea nitrogen (BUN), glomerular filtration rate (GFR), urine output, diabetes, hypertension, age, and CKD status.

The goal is to demonstrate how data analytics can be used to explore healthcare datasets and generate meaningful insights.

## 🎯 Project Objectives

- Analyze kidney health indicators.
- Explore relationships between kidney function and CKD status.
- Investigate the relationship between diabetes, hypertension, and CKD.
- Examine patient age and kidney health patterns.
- Explore medication and water intake information.
- Identify trends and patterns in the dataset.

## 📊 Dataset Information

- Total Records: 5,000
- Total Columns: 11
- Dataset Format: CSV

### Dataset Features

| Feature | Description |
|---|---|
| Creatinine | Blood creatinine level |
| BUN | Blood urea nitrogen |
| GFR | Glomerular filtration rate |
| Urine_Output | Urine output measurement |
| Diabetes | Diabetes indicator |
| Hypertension | Hypertension indicator |
| Age | Patient age |
| Protein_in_Urine | Urine protein measurement |
| Water_Intake | Water intake measurement |
| Medication | Medication category |
| CKD_Status | CKD classification indicator |
